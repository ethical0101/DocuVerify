# Datasets

## Primary dataset: synthetic identity cards + educational certificates

**This is DocuVerify's primary and only dataset actually used to build and evaluate this hackathon
prototype.** It is generated entirely by this repository's own scripts — no real people, no real
institutions, no scraped personal data.

| Generator | Output |
|---|---|
| `scripts/generate_synthetic_documents.py` | Genuine fictional identity cards (`data/synthetic/identity/genuine/`) and university certificates (`data/synthetic/education/genuine/`), each with a ground-truth JSON of field values and field bounding boxes. |
| `scripts/generate_forgeries.py` | Forged derivatives of every genuine document (`.../forged/`), applying text replacement, typography manipulation (mismatched font size), and copy-paste, each re-encoded through a low-quality JPEG pass on just the edited region (mimicking the compression/noise mismatch real paste/edit tooling leaves behind). Ground truth (`forged_manifest.json`) records the exact forgery type(s) and region bbox(es) per forged document. |
| `scripts/prepare_datasets.py` | Splits into train/val/test (70/15/15) **by source document ID**, so a genuine document and every one of its forged derivatives always land in the same split — this prevents the classic leakage bug where a model implicitly memorizes "this exact background/layout = genuine" from having seen the unforged twin in training. |

Current generated size (`--count 40`, i.e. 40 genuine identity cards + 40 genuine certificates):
80 genuine + 240 forged = 320 documents. See `data/synthetic/split_stats.json` for the exact per-split
counts after running the pipeline.

Regenerate everything with:
```bash
python scripts/generate_synthetic_documents.py --count 40
python scripts/generate_forgeries.py
python scripts/prepare_datasets.py
```

All names, universities, ID numbers, and photos-as-placeholders in these documents are fictional. Every
generated image is watermarked with the text "FICTIONAL SPECIMEN".

## Datasets considered but NOT downloaded in this build

The hackathon brief suggested several public identity-forensics datasets as optional supplements. Given
a 24-hour build window and this environment's resources (RTX 3050 4GB VRAM, ~50GB free disk, no
guaranteed high-bandwidth access to Zenodo/Kaggle mid-build), we made a deliberate call: **ship a
complete, working, honestly-evaluated pipeline on a small synthetic dataset rather than spend hours on
partial multi-GB downloads that might not finish.** `scripts/download_datasets.py` documents this
decision in code and exits gracefully rather than attempting large downloads.

| Dataset | Purpose | Why skipped this build |
|---|---|---|
| [SIDTD](https://github.com/Oriolrt/SIDTD_Dataset) | Genuine vs. forged ID/travel documents (built on MIDV-2020) | Multi-GB, requires dataset-specific access; not attempted to protect the time budget. Documented here as the natural first external dataset to add post-hackathon. |
| [IDNet](https://zenodo.org/records/13852734) | Large-scale synthetic ID fraud (text replacement, face morph, portrait substitution) | The full release is 100+GB — explicitly out of scope per the resource-aware dataset rule. A curated 500–2000 sample subset was the target if bandwidth allowed; it did not in this build. |
| [MIDV-500](https://arxiv.org/abs/1807.05786) | Document boundary detection / segmentation ground truth | Our document-boundary detector (`app/services/document_detection/detector.py`) uses classical contour-based perspective correction instead, which needs no training data. |
| [DocTamper](https://github.com/qcf-568/DocTamper) | Tampered-text-region localization | Explicitly gated behind a non-commercial access/request process per its repo — skipped per the brief's instruction not to wait on external access requests during the hackathon. |

If you want to extend this project with real data post-hackathon, `scripts/download_datasets.py` is the
intended integration point — it already checks network availability and is structured to add
dataset-specific fetchers behind the same `--small` flag.
